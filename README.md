# 매쓰헌터 검수 결과 뷰어

조회 전용 공유본입니다. 검수 기록 기준일: 2026-10-15.

문제·해설 이미지는 운영 서버에서 불러옵니다. 검수 기록은 배포 시점에 고정되며 이후 이미지와 달라질 수 있습니다.

이 저장소의 Settings → Pages → Deploy from a branch → main / (root)로 게시합니다.

승인·데이터 수정·개인정보·전체 문제풀 데이터·로컬 작업경로는 포함하지 않습니다. 문제 이미지와 공개 검수 기록은 열람 가능합니다. 콘텐츠의 저작권은 각 권리자에게 있습니다.


## 공장 V3 공유 검수

[V3 화면](https://minji-learning-lab.github.io/mathhunter-review-viewer/v3/)은 별도의 로컬 서버 없이 사용할 수 있습니다. 원본 `ORIG`와 번호별 `TWIN01, TWIN02, …`를 비교합니다.

- 공개 저장소에는 UI와 신뢰된 렌더러 코드만 포함합니다. 문항 JSON·삽화·PNG·폰트·실행 ZIP·인증은 포함하지 않습니다.
- 비공개 math-content-team의 실행 ZIP을 사용자가 선택하면 브라우저 메모리에서 전체 manifest 파일 해시를 확인합니다. ZIP 내 JS/HTML을 실행하지 않습니다.
- 1·2학년 코드 렌더, 보관 PNG 다운로드, 검수 메모 JSON 다운로드를 제공합니다. 생성·규칙 저장·게이트 재판정·PM 승인은 비공개 공장에서 수행합니다.
- 3·4학년 완료 변형 자료가 포함된 ZIP은 TWIN01/02의 Q/A와 최신 메타데이터·유형별 차단 원인을 함께 보여줍니다. 제공되지 않은 ORIG를 임의로 만들거나 TWIN01로 대신하지 않습니다. 완료 이미지를 코드 렌더로 표시하지 않습니다.
- GitHub 로그인 토큰 입력·데이터 업로드·외부 분석·localStorage·IndexedDB·서비스 워커를 사용하지 않습니다. 자료 비우기/새로고침 시 다시 ZIP을 선택해야 합니다. 메모는 필요할 때 다운로드하여 비공개 저장소에 보관합니다.
- 기존 검수 결과 페이지와 data.js는 보존합니다.

검증: 실제 비공개 ZIP의 메모리 읽기·파일 해시·폰트/이미지·코드 Q/A·메모 다운로드·자료 비우기와 정적 GET 외 업로드 요청이 없는지 확인합니다. 문항의 수학/교육 승인 도구는 아닙니다.
